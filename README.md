## Опис проєкту
Android-застосунок на Java для відстеження фізичної активності в реальному часі. Додаток підраховує кроки, обчислює пройдену дистанцію та витрачені калорії, веде таймер тренування й відображає прогрес виконання денної цілі.

## Основний функціонал
- **Робота з датчиками (`SensorManager`):**
  - Використання апаратного лічильника кроків (`Sensor.TYPE_STEP_COUNTER`).
  - Автоматичний перехід на акселерометр (`Sensor.TYPE_ACCELEROMETER`) із пороговим детектором кроків, якщо крокомір відсутній.
  - Обробка runtime-дозволу `ACTIVITY_RECOGNITION` (Android 10+).
- **Метрики та прогрес:**
  - Дистанція (км) та витрачені калорії (ккал) у реальному часі.
  - Індикатор денної цілі (`LinearProgressIndicator`, ціль — 1000 кроків).
  - Таймер активного тренування у форматі `MM:SS`.
- **Локалізація (i18n):**
  - Підтримка української (`values-uk`) та англійської (`values`) мов із миттєвим перемиканням кнопкою `UA / EN` через `AppCompatDelegate.setApplicationLocales()`.
- **Збереження стану:**
  - Збереження кроків і часу в `SharedPreferences`.
  - Збереження активного стану трекінгу через `onSaveInstanceState` (таймер не скидається при зміні мови чи повороті екрана).
- **Логування:**
  - Інтегрована бібліотека **Timber** (`FitnessTrackerApp`).
- **Інтерфейс і тестування:**
  - Дизайн **Material 3** із кастомною рожевою темою (`Theme.FitnessTracker`).
  - Кнопка `+50 кроків (Тест)` для швидкої перевірки функціоналу на емуляторах без датчиків.
